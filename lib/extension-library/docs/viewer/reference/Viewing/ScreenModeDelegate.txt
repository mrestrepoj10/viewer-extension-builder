# ScreenModeDelegate

## new ScreenModeDelegate(viewer)

Virtual base class for screen mode manipulation.

Derive from this class and use it to allow viewer to go full screen.

### Parameters

viewer* (Autodesk.Viewing.Viewer3D) | Viewer instance.
