# ThemingColorChangedCallback

## Parameters

instanceIds* (number, Array.<number>, undefined) | The ids of the affected instances or undefined if all instances are affected.
color* (Autodesk.Viewing.Math.Vector4, undefined) | The new theming color of the instance. Undefined means that theming is cleared.
