# Matrix4

## new Matrix4(useDoublePrecision)

Represents a 4x4 matrix

### Parameters

useDoublePrecision (boolean) | Whether to use double precision (Float64Array) or single precision (Float32Array)

# Properties

elements (Float32Array, Float64Array) | A column-major list of matrix values. Precision is set on construction.
isDoublePrecision (boolean) | Whether the matrix uses double precision (Float64Array) or single precision (Float32Array).
