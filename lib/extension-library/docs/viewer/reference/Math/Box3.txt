Autodesk.Viewing.Math

# Box3

## new Box3(min, max)

Represents a 3D axis-aligned bounding box.

### Parameters

min (Autodesk.Viewing.Math.Vector3) | The minimum (lower) corner. Defaults to (+Infinity, +Infinity, +Infinity).
max (Autodesk.Viewing.Math.Vector3) | The maximum (upper) corner. Defaults to (-Infinity, -Infinity, -Infinity).

# Properties

min (Autodesk.Viewing.Math.Vector3) | The minimum (lower) corner of the box.
max (Autodesk.Viewing.Math.Vector3) | The maximum (upper) corner of the box.

## isFinite()

Check whether every component of both corners is a finite number. This does not overlap with isEmpty(): comparisons against NaN are always false, so a box with NaN corners reports as non-empty.

### Returns

type | description
boolean | True if no corner component is NaN or an infinity.
