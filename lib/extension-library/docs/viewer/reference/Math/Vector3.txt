# Vector3

## new Vector3(x, y, z)

A 3D vector with components x, y and z.

### Parameters

x (number) | The x component (defaults to 0).
y (number) | The y component (defaults to 0).
z (number) | The z component (defaults to 0).

# Properties

x (number) | The x component of the vector.
y (number) | The y component of the vector.
z (number) | The z component of the vector.
