Autodesk.Viewing

# Private

Private classes are intended to be used only for debugging. Private classes can change and may be removed. We recommend that you do not rely on these classes. Do not use them in production code.

# Constants

## Prefs3D

Preference names that can be used to set Autodesk.Viewing.Private.Preferences These preference names only apply for 3D models.

type
Prefs3D

## Prefs2D

Preference names that can be used to set Autodesk.Viewing.Private.Preferences These preference names only apply for 2D models.

type
Prefs2D

## Prefs

Preference names that can be used to set Autodesk.Viewing.Private.Preferences These preference names are shared between both 3D and 2D models.

type
Prefs

## VIEW_TYPES

View types used for setting the viewType preference.

type
VIEW_TYPES

## FPS_TARGET_MODES

FPS target modes used for setting the progressiveFpsTarget preference.

type
FPS_TARGET_MODES
